### 👨‍💻 About Me

I am a **Software Development Engineer & AI Systems Architect** passionate about building high-performance, fault-tolerant distributed applications, event-driven data streaming pipelines, and autonomous AI agents.

- 🔭 **Currently Building:** [Astra Agent](https://github.com/KDM14/astra-agent) — an open-source, evidence-verified autonomous AI agent engine.
- ⚡ **Core Strengths:** Test-Driven Development (TDD), Microservices, RESTful API Engineering, Low-Latency Streaming, and Cloud Infrastructure.
- 💼 **Experience:** Hands-on industry background at **Quantiphi** and **Ambiquest** delivering high-throughput APIs, automated regression suites, and cloud pipelines.
- 🎯 **Design Philosophy:** Clean code, SOLID design patterns, reproducible environments, and defense-in-depth security.
